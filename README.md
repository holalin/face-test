

## 项目概述

这是一个基于DINOv3视觉模型的面部情绪识别系统。项目使用深度学习方法，结合传统计算机视觉技术，实现了从数据采集到实时情绪识别的完整流程。

## 项目主要功能

### 1. **数据采集模块**
- `collect_personal_dataset.py` - 摄像头实时数据采集工具
  - 按1-7键选择情绪标签（1:惊讶, 2:恐惧, 3:厌恶, 4:开心, 5:伤心, 6:愤怒, 7:平淡）
  - 使用Haar级联分类器检测人脸
  - 实时显示采集状态，按C或空格键拍照保存
  - 数据保存在 `dataset_personal/train/` 文件夹下，按标签分目录

### 2. **特征提取模块**
- `dinov3_features.py` - 使用DINOv3模型提取图像特征
  - 加载本地DINOv3模型（384维小模型）
  - 从数据集图像中提取CLS token特征
  - 生成特征矩阵并保存为 `.npy` 文件
  - 支持训练集和测试集的特征提取

### 3. **分类器训练模块**
- `test1.py` - 训练情绪分类器
  - 使用逻辑回归（LogisticRegression）作为分类器
  - 加载提取的特征和标签进行训练
  - 保存训练好的分类器为 `emotion_classifier.pkl`

### 4. **实时预测模块**
- `predict.py` - 实时情绪识别
  - 打开摄像头进行实时人脸检测和情绪识别
  - 使用DINOv3提取特征 + 预训练分类器进行预测
  - 显示各情绪类别的概率分布
  - 添加平滑处理（10帧历史平均）提高稳定性

### 5. **模型文件**
- `model/` 目录包含DINOv3预训练模型
  - config.json - 模型配置（ViT架构，384 hidden size，12层）
  - model.safetensors - 模型权重
  - preprocessor_config.json - 图像预处理配置

## 项目特点

1. **端到端解决方案**：从数据采集到实时识别完整流程
2. **轻量化设计**：使用DINOv3小模型（384维），适合实时应用
3. **用户友好界面**：提供直观的摄像头界面和操作提示
4. **模块化结构**：各功能模块分离，便于维护和扩展
5. **实时处理**：结合Haar级联分类器进行快速人脸检测

## 数据组织

- `dataset_personal/train/` - 训练数据，按1-7子目录分类
- `features_train.npy`, `labels_train.npy` - 提取的训练特征和标签
- `features_test.npy`, `labels_test.npy` - 测试数据（如果存在）

## 技术栈

- **计算机视觉**：OpenCV, Haar级联分类器
- **深度学习**：PyTorch, Transformers库, DINOv3模型
- **机器学习**：Scikit-learn, 逻辑回归
- **数据处理**：NumPy, PIL

这个项目适合用于个人情绪识别应用、人机交互研究或作为更复杂情绪分析系统的基础组件。
